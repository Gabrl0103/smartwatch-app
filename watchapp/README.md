# watchapp

Aquí va el proyecto de Android Studio (Wear OS).

1. En Android Studio: File → New → New Project → pestaña Wear OS → "Empty Wear App".
2. Name: `watchapp` · Package name: `com.rumbo.watchapp` · Minimum SDK: API 30.
3. Guarda el proyecto DENTRO de esta carpeta (que `build.gradle` quede en `watchapp/`).
4. Estructura por capas dentro de `app/src/main/java/com/rumbo/watchapp/`:
   `domain/`, `application/`, `infrastructure/`, `presentation/`, `di/`.
